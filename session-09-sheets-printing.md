# Session 09: Sheets and Printing

## Goal

Assemble drawing sheets and understand the basic print and export workflow.

## Prerequisites

- Several coordinated views ready for documentation
- Basic annotation and view naming confidence

## Key Concepts

- Sheets
- Titleblocks
- Sheet numbering
- Viewports
- View placement
- View scales
- Title block information
- View title and extension line adjustment
- Activate and deactivate views on sheets
- PDF export
- DWG export overview

## Demonstration

Explain sheets as containers for views and schedules. Show how titleblocks work, how sheet numbers are managed, and how viewports control placed views.

Demonstrate PDF export settings, print setup, and the basic considerations for DWG export. Include sheet composition tasks from the ACU objectives: changing the size of a placed view, adjusting view title and extension line, activating and deactivating a view on a sheet, and entering information on a title block.

## Exercise

1. Create a new sheet with a titleblock.
2. Add a floor plan to the sheet.
3. Add a section and elevation.
4. Align views and adjust viewport titles and extension lines.
5. Activate and deactivate a view on the sheet.
6. Enter information on the title block.
7. Check view scales and change the size of a placed view.
8. Export the sheet to PDF.
9. Review output quality and naming.

## Checklist

- [ ] I can create a sheet.
- [ ] I can place views on a sheet.
- [ ] I can manage viewports and view titles.
- [ ] I can activate/deactivate views on sheets and edit title block information.
- [ ] I can check view scale before printing.
- [ ] I can export a PDF.

## Homework

- Create a small presentation sheet set.
- Export the sheet set as PDFs.
