# Session 10: Components and Basic Families

## Goal

Place and edit Revit families while understanding family categories and placement behaviour.

## Prerequisites

- Basic modelling and view navigation confidence
- Access to office or sample Revit families

## Key Concepts

- System families
- Loadable families
- In-place families
- Family categories
- Hosted components
- Non-hosted components
- Family parameters
- Type catalogs

## Demonstration

Explain families as the building blocks of Revit projects. Compare system families, loadable families, and in-place families, and discuss when each is appropriate.

Demonstrate component placement, rotation, mirroring, hosting requirements, and basic family type editing.

## Exercise

1. Load a family into the project.
2. Place hosted and non-hosted components.
3. Rotate and mirror components.
4. Duplicate and modify a family type.
5. Review type and instance parameters.
6. Place furniture or equipment in a room layout.
7. Review office family naming standards.

## Checklist

- [ ] I can identify system and loadable families.
- [ ] I can load a family.
- [ ] I can place hosted and non-hosted components.
- [ ] I can modify family types.
- [ ] I understand basic family parameters.

## Homework

- Review office family standards.
- Place and organise furniture in a sample plan.
