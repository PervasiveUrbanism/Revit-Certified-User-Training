# Training Schedule

The programme is structured as short, practical one-hour sessions suitable for delivery in an office environment. It assumes learners have little to moderate Revit experience and aims to prepare them for the Autodesk Certified User Revit for Architectural Design certification.

## Session Overview

### Session 1: Introduction to Revit and Interface

Objectives:

- Understand BIM vs CAD
- Navigate the Revit interface
- Understand the Project Browser and Properties Palette
- Use selection and navigation tools

Exercise:

- Open a project
- Navigate between views
- Select and modify elements
- Create duplicate views

Homework:

- Practice navigation shortcuts
- Open and explore sample projects

### Session 2: Levels, Grids and Basic Setup

Objectives:

- Understand datums
- Create and modify levels and grids
- Understand view relationships

Exercise:

- Create levels
- Add grids
- Rename views automatically
- Align datums

Homework:

- Recreate a simple structural grid layout

### Session 3: Walls, Doors and Windows

Objectives:

- Model basic architectural elements
- Understand type vs instance properties

Exercise:

- Build a simple floor plan
- Add doors and windows
- Modify wall types

Homework:

- Create variations of wall types

### Session 4: Floors, Roofs and Ceilings

Objectives:

- Create horizontal building elements
- Understand sketch-based tools

Exercise:

- Create floors
- Add a roof
- Create a reflected ceiling plan

Homework:

- Model a simple house roof

### Session 5: Views, Visibility and Graphics

Objectives:

- Control model visibility
- Understand view-specific settings

Exercise:

- Apply Visibility/Graphics overrides
- Create view templates
- Troubleshoot visibility issues

Homework:

- Create presentation and working views

### Session 6: Annotation and Dimensions

Objectives:

- Document the model correctly
- Use annotation tools effectively

Exercise:

- Dimension a floor plan
- Tag doors and windows
- Create annotated views

Homework:

- Annotate a complete room layout

### Session 7: 2D Drafting and Detailing

Objectives:

- Understand view-specific detailing tools
- Create 2D details in Revit
- Distinguish between model and drafting elements

Exercise:

- Create a wall section detail
- Add filled regions
- Add annotations and detail components
- Create a drafting view detail sheet

Homework:

- Recreate a simple construction detail from a PDF or CAD reference

### Session 8: Sections, Elevations and Callouts

Objectives:

- Generate construction documentation views

Exercise:

- Create building sections
- Add interior elevations
- Create enlarged callout plans

Homework:

- Produce one coordinated drawing sheet

### Session 9: Sheets and Printing

Objectives:

- Assemble drawing sheets
- Understand the sheet workflow

Exercise:

- Create sheets
- Place views
- Export PDFs

Homework:

- Create a presentation sheet set

### Session 10: Components and Basic Families

Objectives:

- Place and edit families
- Understand family categories

Exercise:

- Load families
- Modify family types
- Place furniture and components

Homework:

- Review office family standards

### Session 11: Basic Family Editing

Objectives:

- Understand Family Editor basics

Exercise:

- Create a simple parametric box family
- Add dimensions and parameters

Homework:

- Modify an existing family

### Session 12: Schedules and Quantities

Objectives:

- Extract model data
- Create schedules
- Understand data-driven workflows
- Learn how schedules support BIM coordination

Exercise:

- Create a door schedule
- Create a room schedule
- Filter schedule data
- Create a simple quantity schedule

Homework:

- Create a furniture schedule
- Review office schedule standards

### Session 13: Rooms, Areas and Tags

Objectives:

- Understand spatial elements
- Learn room-based BIM workflows
- Understand area calculations and data coordination

Exercise:

- Create rooms
- Tag rooms
- Generate a room schedule
- Create a coloured room plan

Homework:

- Create a complete room data sheet
- Review office naming standards

### Session 14: Linked Models and Coordination Basics

Objectives:

- Understand linked workflows
- Learn BIM coordination principles
- Understand coordinate management and model exchange
- Understand multidisciplinary collaboration workflows

Exercise:

- Link a model
- Adjust linked visibility
- Position linked files
- Test shared coordinate workflows

Homework:

- Review office coordination workflows
- Compare consultant model positioning methods

### Session 15: Worksharing and Collaboration Basics

Objectives:

- Understand multi-user workflows
- Learn central model management
- Understand collaborative BIM responsibilities
- Learn best practice for stable team workflows

Exercise:

- Open a local file
- Borrow elements
- Sync changes
- Create and manage worksets
- Resolve ownership conflicts

Homework:

- Practice collaborative workflows
- Review office BIM standards

### Session 16: Troubleshooting Workshop and Mock Review

Objectives:

- Diagnose common Revit issues
- Prepare learners for certification-style workflows

Exercise:

- Solve prepared troubleshooting scenarios
- Complete a timed mock exam task
- Group review and final questions

Homework:

- Troubleshoot provided practice model

## Optional Advanced Sessions

- Phasing and design options
- Materials and rendering basics
- Filters and graphic standards
- Advanced documentation standards
