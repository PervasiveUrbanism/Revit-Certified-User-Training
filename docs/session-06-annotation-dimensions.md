# Session 06: Annotation and Dimensions

## Goal

Document the model clearly using dimensions, text, notes, and tags.

## Prerequisites

- A simple model with walls, doors, windows, and rooms or spaces
- Basic view setup confidence

## Key Concepts

- Aligned dimensions
- Temporary dimensions
- Witness lines
- Equality constraints
- Text styles
- Leaders
- Tags
- Tag families

## Demonstration

Show how dimensions are placed, edited, and cleaned up. Explain witness lines, temporary dimensions, equality constraints, and how dimensions support coordination rather than just presentation.

Then introduce text notes and tags. Explain that tags display model data, while text is independent annotation.

## Exercise

1. Open a floor plan suitable for documentation.
2. Add aligned dimensions to exterior and interior walls.
3. Adjust witness lines.
4. Add room or general notes.
5. Tag doors and windows.
6. Review tag values against model properties.
7. Clean up annotation placement for readability.

## Checklist

- [ ] I can place aligned dimensions.
- [ ] I can edit witness lines.
- [ ] I understand temporary dimensions.
- [ ] I can add text with leaders.
- [ ] I can tag doors and windows.

## Homework

- Annotate a complete room layout.
- Check that tags match the model data they display.
