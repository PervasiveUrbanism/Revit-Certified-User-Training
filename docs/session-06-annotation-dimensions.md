# Session 06: Annotation and Dimensions

## Goal

Document the model clearly using dimensions, text, notes, and tags.

## Prerequisites

- A simple model with walls, doors, windows, and rooms or spaces
- Basic view setup confidence

## Key Concepts

- Aligned dimensions
- Linear, angular, radial, and diameter dimensions
- Temporary dimensions
- Witness lines
- Equality constraints
- Locked dimensions
- Dimension types
- Text styles
- Model text
- Text alignment
- Leaders
- Tags
- Tag All
- Tag families

## Demonstration

Show how dimensions are placed, edited, and cleaned up. Explain linear, aligned, angular, radial, and diameter dimensions, witness lines, temporary dimensions, equality constraints, locked dimensions, dimension types, and how dimensions support coordination rather than just presentation.

Then introduce text notes, model text, and tags. Explain that tags display model data, while text is independent annotation. Demonstrate text type duplication, font and size changes, leaders, horizontal and vertical justification, Tag by Category, Tag All, room tags, and editing door or room numbers through tags.

## Exercise

1. Open a floor plan suitable for documentation.
2. Add aligned dimensions to exterior and interior walls.
3. Add angular, radial, and diameter dimensions where geometry allows.
4. Toggle equality and lock a dimension.
5. Adjust witness lines and apply a dimension type.
6. Add room or general notes and modify a text type.
7. Resize, rotate, justify, and add leaders to text.
8. Place simple model text.
9. Tag doors and windows using Tag by Category and Tag All.
10. Edit a door or room number through a tag.
11. Review tag values against model properties.
12. Clean up annotation placement for readability.

## Checklist

- [ ] I can place aligned dimensions.
- [ ] I can place linear, angular, radial, and diameter dimensions.
- [ ] I can edit witness lines.
- [ ] I understand temporary dimensions.
- [ ] I can use equality, locked dimensions, and dimension types.
- [ ] I can add, align, resize, rotate, and type text with leaders.
- [ ] I can use Tag by Category, Tag All, room tags, and tag-based number edits.

## Homework

- Annotate a complete room layout.
- Check that tags match the model data they display.
