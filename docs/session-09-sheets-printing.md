# Session 09: Sheets and Printing

## Goal

Assemble drawing sheets and understand the basic print and export workflow.

## Prerequisites

- Several coordinated views ready for documentation
- Basic annotation and view naming confidence

## Key Concepts

- Sheets
- Titleblocks
- Sheet numbering
- Viewports
- View placement
- View scales
- PDF export
- DWG export overview

## Demonstration

Explain sheets as containers for views and schedules. Show how titleblocks work, how sheet numbers are managed, and how viewports control placed views.

Demonstrate PDF export settings, print setup, and the basic considerations for DWG export.

## Exercise

1. Create a new sheet with a titleblock.
2. Add a floor plan to the sheet.
3. Add a section and elevation.
4. Align views and adjust viewport titles.
5. Check view scales.
6. Export the sheet to PDF.
7. Review output quality and naming.

## Checklist

- [ ] I can create a sheet.
- [ ] I can place views on a sheet.
- [ ] I can manage viewports and view titles.
- [ ] I can check view scale before printing.
- [ ] I can export a PDF.

## Homework

- Create a small presentation sheet set.
- Export the sheet set as PDFs.
