## File Setup

Recommended setup before each session:

- Upload the exercise file.
- Upload any reference PDFs, CAD files, or family files.
- Confirm everyone can access the shared folder.
- Confirm the Revit version matches the training material.

## Suggested Learner Checklist

- Revit installed and working
- Access to shared training folder
- Mouse with scroll wheel
- Keyboard shortcuts enabled
- Dual screen or second display where available
- Sample project downloaded locally before the session
