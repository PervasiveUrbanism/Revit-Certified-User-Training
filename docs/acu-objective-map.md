## Audit Notes

The original 16-session schedule covered the overall ACU domain, but this review added several explicit exam points that were previously only implied:

- Wall and shaft openings
- Architectural columns on grids
- Straight stairs, ramps, and railings
- Full Modify tool list
- ACU sketch draw tools and keyboard modifiers
- 3D section boxes and camera views
- Underlays and reveal hidden elements
- Text/model text variants and alignment
- Tag All and tag-based number edits
- Dimension type variants and locked dimensions
- Window schedules, itemize every instance, and schedule data entry
- Detail insulation
- Title block data and sheet viewport activation/deactivation
