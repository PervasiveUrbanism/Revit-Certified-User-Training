# Mock Tests

These are original practice questions written to match the style and level of the Autodesk Certified User Revit for Architectural Design exam objectives. They are not official exam questions.

Use them after completing the lessons, or as short diagnostic checks before revising a topic.

## How to Use

- Complete each mock test without looking at the answer key.
- Allow about 30-40 minutes per test.
- For practical questions, describe the correct Revit workflow in order.
- Review weak topics using the linked session pages and the [ACU Objective Map](acu-objective-map.md).

---

# Mock Test 1

## Questions

1. In Revit, what is the main difference between CAD drafting and BIM modelling?

    A. BIM only creates 2D drawings  
    B. BIM uses coordinated model information shared across views  
    C. CAD automatically updates all schedules  
    D. BIM does not use views

2. Which palette is used to edit the instance properties of a selected wall?

    A. Project Browser  
    B. Properties Palette  
    C. View Control Bar  
    D. Status Bar

3. You need a wall to extend from Level 1 to Level 2. Which wall settings are most relevant?

    A. Base Constraint and Top Constraint  
    B. View Scale and Detail Level  
    C. Project Browser and Sheet Number  
    D. Tag Category and Tag Type

4. A wall is being placed on the wrong side of a grid line. Which wall setting should you check first?

    A. Wall location line  
    B. Room name  
    C. Sheet issue date  
    D. Text alignment

5. Which values are commonly adjusted when placing windows?

    A. Crop boundary and view template  
    B. Sill height and head height  
    C. Sheet number and viewport title  
    D. Room separation and colour scheme

6. What is the purpose of a grid bubble value?

    A. It controls the wall type  
    B. It names or identifies the grid line  
    C. It sets the room area calculation  
    D. It changes the view scale

7. Which tool would you use to create a floor from surrounding walls?

    A. Pick Walls  
    B. Tag All  
    C. Duplicate View  
    D. Reload Latest

8. In roof sketch mode, what does "Defines Slope" control?

    A. Whether an edge creates roof slope  
    B. Whether the view is cropped  
    C. Whether a room is bounded  
    D. Whether a wall is structural

9. Which view type is used for reflected ceiling layout work?

    A. Camera view  
    B. Drafting view  
    C. Reflected ceiling plan  
    D. Sheet view

10. Which Modify tool is most appropriate for making two selected elements line up?

    A. Align  
    B. Array  
    C. Split  
    D. Pin

11. Which view setting controls how much model detail is shown?

    A. Detail Level  
    B. Room Number  
    C. Grid Bubble  
    D. Sheet Name

12. What is the purpose of Reveal Hidden Elements?

    A. To show model elements that have been hidden in a view  
    B. To open the Family Editor  
    C. To duplicate a schedule  
    D. To create a new level

13. Which option creates a view that keeps annotation from the original view?

    A. Duplicate  
    B. Duplicate with Detailing  
    C. Duplicate as Blank  
    D. Duplicate as Schedule

14. What is a section box used for in a 3D view?

    A. Cropping the 3D model volume  
    B. Adding text to a sheet  
    C. Renaming a room  
    D. Loading a family

15. Which family type is built into the project environment and cannot be loaded as a separate `.rfa` file?

    A. System family  
    B. Loadable family  
    C. Detail component  
    D. Annotation symbol

16. You need a second wall type with a thicker layer build-up. What should you do?

    A. Duplicate the wall type and edit the structure  
    B. Delete all existing walls  
    C. Change the Project Browser  
    D. Create a new sheet

17. Which annotation tool displays model data such as a door number?

    A. Text  
    B. Tag  
    C. Detail Line  
    D. Filled Region

18. Which dimension type is best suited to dimensioning a wall at an angle?

    A. Radial  
    B. Diameter  
    C. Angular  
    D. Spot Room

19. In a door schedule, which setting controls whether identical items are grouped or listed individually?

    A. Itemize every instance  
    B. Crop region  
    C. View range  
    D. Section box

20. You place a view on a sheet and need to edit model content inside it. What should you do?

    A. Activate the view on the sheet  
    B. Rename the title block  
    C. Delete the viewport  
    D. Change the sheet scale

# Mock Test 2

## Questions

1. Which Revit feature best supports the idea that one model can generate plans, sections, elevations, schedules, and sheets?

    A. Exploded CAD imports  
    B. Manual drafting only  
    C. Unlinked annotation  
    D. BIM coordination

2. In the Project Browser, what would you normally use to open a floor plan?

    A. Families only  
    B. Views  
    C. Materials only  
    D. Render settings only

3. You rename a level and Revit asks whether to rename corresponding views. What does this indicate?

    A. Levels can be associated with plan views  
    B. Levels are only text labels  
    C. Levels are only used for sheets  
    D. Levels control material colours

4. Which element type is commonly placed on grid intersections?

    A. Text note  
    B. Filled region  
    C. Architectural column  
    D. Schedule header

5. A door flips the wrong way after placement. What should you use?

    A. View template  
    B. Flip controls  
    C. Crop region  
    D. Schedule formatting

6. Which opening tool is appropriate for a vertical opening through several levels?

    A. Tag All  
    B. View duplicate  
    C. Crop region  
    D. Shaft opening

7. Which sketch tools are commonly used for floor and roof boundaries?

    A. Tag, schedule, sheet, print  
    B. Line, rectangle, pick lines, pick walls  
    C. Browser, ribbon, status bar, titleblock  
    D. Sync, reload, relinquish, audit

8. You need to place a simple stair between two levels. Which elements may be involved?

    A. Run and landing  
    B. Room tag and text note  
    C. Sheet number and issue date  
    D. Crop region and underlay

9. Which Modify tool repeats selected elements in a linear or circular pattern?

    A. Mirror  
    B. Trim  
    C. Array  
    D. Pin

10. What does Pin/Unpin help control?

    A. Whether a schedule can sort by type  
    B. Whether an element can be moved accidentally  
    C. Whether a sheet has a title block  
    D. Whether a room is named

11. Which view type is best for a 2D detail that is not modelled in 3D?

    A. Camera view  
    B. Sheet view  
    C. Schedule view  
    D. Drafting view

12. Which view setting determines the vertical slice visible in a plan?

    A. Tag Type  
    B. Family Category  
    C. View Range  
    D. Door Mark

13. What does an underlay help you do?

    A. See another level or view reference beneath the current view  
    B. Rename a sheet  
    C. Edit a material asset  
    D. Create a door schedule

14. Which view is created from a camera position?

    A. Drafting view  
    B. Camera view  
    C. Schedule view  
    D. Legend-only view

15. Which Revit family category is created and edited outside the project, then loaded into the project?

    A. System family  
    B. Project browser family  
    C. Loadable family  
    D. View family

16. You want to change the material of a wall type layer. Where would you normally look?

    A. Type Properties / Edit Structure  
    B. Sheet list only  
    C. Room tag only  
    D. Print preview only

17. Which command can tag multiple eligible elements in one view?

    A. Split Element  
    B. Section Box  
    C. Array  
    D. Tag All

18. What is a witness line in dimensioning?

    A. The outline of a crop region  
    B. The extension line that connects a dimension to referenced geometry  
    C. A schedule sorting field  
    D. A title block parameter

19. Which schedule controls are used to organise visible data?

    A. Crop, reveal, orbit  
    B. Wall join, location line, flip control  
    C. Fields, filters, sorting/grouping  
    D. ViewCube, Steering Wheel, Pan

20. When placing a view on a sheet, which items may need adjustment?

    A. Viewport position, view title, extension line, and view scale  
    B. Only the Project Browser font  
    C. Only the Revit installation path  
    D. Only the status bar
