# Session 13: Rooms, Areas and Tags

## Goal

Use spatial elements for room data, tagging, schedules, and area-based workflows.

## Prerequisites

- A bounded model layout
- Basic schedule and annotation knowledge

## Key Concepts

- Room placement
- Room boundaries
- Room bounding elements
- Room separation lines
- Room tags
- Room names and numbers
- Room schedules
- Area schemes
- Area plans
- Colour schemes
- Legend Views

## Demonstration

Explain rooms as intelligent spatial data elements rather than physical model geometry. Show how rooms depend on enclosed boundaries and how warnings appear when boundaries fail.

Demonstrate room tags, room data consistency, room bounding settings on elements, area plan concepts, and colour schemes for communicating spatial information.

## Exercise

1. Place rooms in a simple plan.
2. Add room separation lines where needed.
3. Rename and number rooms consistently.
4. Tag rooms.
5. Identify and set whether an element is room bounding.
6. Create a room schedule.
7. Create a coloured room plan.
8. Review room warnings and fix boundary issues.

## Checklist

- [ ] I can place rooms.
- [ ] I can use room separation lines.
- [ ] I can identify and set room bounding elements.
- [ ] I can tag rooms.
- [ ] I can create a room schedule.
- [ ] I understand the basics of area plans.
