# Session 16: Troubleshooting Workshop and Mock Review

## Goal

Diagnose common Revit issues and prepare for certification-style task workflows.

## Prerequisites

- Sessions 01-15 completed
- Practice model with prepared troubleshooting scenarios

## Key Concepts

- Visibility troubleshooting
- View range
- Filters and templates
- Hosted element issues
- Constraints
- Joined geometry
- Missing tags
- Broken schedules
- Sheet coordination
- Exam strategy

## Demonstration

Walk through a structured troubleshooting checklist. Start with visibility problems, then move to modelling issues, documentation issues, and schedule problems.

Finish with an exam-style review: time management, navigation strategy, keyboard shortcuts, and avoiding common mistakes under pressure.

## Exercise

1. Diagnose prepared visibility issues.
2. Fix a view range problem.
3. Resolve a missing hosted element.
4. Repair missing or incorrect tags.
5. Check a broken schedule.
6. Complete a timed mock exam task.
7. Review answers as a group.

## Checklist

- [ ] I can use a structured visibility checklist.
- [ ] I can identify view range issues.
- [ ] I can diagnose hosted element problems.
- [ ] I can repair documentation and schedule issues.
- [ ] I can approach exam tasks efficiently.

## Homework

- Troubleshoot the provided practice model.
- Review weak topics before certification practice.
