# Session 10: Components and Basic Families

## Goal

Place and edit Revit families while understanding family categories and placement behaviour.

## Prerequisites

- Basic modelling and view navigation confidence
- Access to office or sample Revit families

## Key Concepts

- System families
- Loadable families
- In-place families
- Family categories
- Hosted components
- Non-hosted components
- Family parameters
- Type catalogs
- Material reassignment

## Demonstration

Explain families as the building blocks of Revit projects. Compare system families, loadable families, and in-place families, and discuss when each is appropriate.

Demonstrate in place families and the basic modelling tools.

## Exercise

1. Discuss where to find families
2. Load an external window family into the project.
3. Discuss the different types of families (2D families, hosted families etc. ) and where / when to use them.
4. Create an In Place family - for example a door or a table.


## Finding Families

Look for new families in this order:

1. The office family library or BIM standards folder.
2. Families already loaded into a recent office project.
3. Autodesk sample content and Revit default libraries.
4. Manufacturer BIM content, if it is needed for a real project.

For this lesson, the main hosted family will be a window family and the main non-hosted family will be a furniture family. Doors have already been introduced in Session 03, so the focus here is on loading, placing, duplicating, and modifying family types.

## Checklist

- [ ] I can identify system and loadable families.
- [ ] I can load a family.
- [ ] I can place hosted and non-hosted components.
- [ ] I can modify family types.
- [ ] I know the basic family modelling tools

## Homework

- Place and organise furniture in a sample plan.
