# Session 15: Worksharing and Collaboration Basics

## Goal

Understand central/local file workflows, worksets, ownership, and collaboration habits that keep Revit projects stable.

## Prerequisites

- Basic model navigation and editing confidence
- Access to a workshared practice model or demonstration file

## Key Concepts

- Worksharing
- Central files
- Local files
- Synchronize with Central
- Reload Latest
- Element ownership
- Borrowing
- Worksets
- Relinquishing ownership
- Model maintenance

## Demonstration

Explain that Revit worksharing is not the same as a live shared document. Users borrow and own elements, synchronise changes, reload updates, and relinquish ownership.

Demonstrate central/local file concepts, worksets, editable status, sync habits, and common collaboration risks.

## Exercise

1. Open or create a local file from a central model.
2. Borrow and edit model elements.
3. Use Reload Latest.
4. Synchronize with Central.
5. Create and manage worksets.
6. Review ownership status.
7. Resolve a prepared ownership conflict.

## Checklist

- [ ] I understand central and local files.
- [ ] I can synchronise with central.
- [ ] I can use Reload Latest.
- [ ] I understand element ownership and borrowing.
- [ ] I understand what worksets are for.

## Homework

- Practice collaborative workflows.
- Review office BIM standards and model maintenance habits.
