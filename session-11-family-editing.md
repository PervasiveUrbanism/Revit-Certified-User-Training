# Session 11: Basic Family Editing

## Goal

Understand the Family Editor and create a simple parametric family.

## Prerequisites

- Session 10 completed
- Basic knowledge of parameters and family types

## Key Concepts

- Family templates
- Family categories
- Family Editor environment
- Reference planes
- Dimensions and constraints
- Locked geometry
- Extrusions
- Voids
- Material parameters

## Demonstration

Open the Family Editor and explain how templates, categories, reference planes, dimensions, and parameters define family behaviour.

Demonstrate creating a simple extrusion, constraining it to reference planes, adding dimensions, and turning dimensions into parameters.

## Exercise

1. Create a new family from a suitable template.
2. Add reference planes.
3. Add dimensions and lock constraints.
4. Create a simple extrusion.
5. Add width, depth, and height parameters.
6. Test multiple family types.
7. Load the family into a project.

## Checklist

- [ ] I can open and navigate the Family Editor.
- [ ] I can create reference planes.
- [ ] I can constrain geometry.
- [ ] I can create simple parameters.
- [ ] I can load a family into a project.

## Homework

- Modify an existing family.
- Add one new type to the family and test it in a project.
