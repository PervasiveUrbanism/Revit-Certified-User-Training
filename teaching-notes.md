# Teaching Notes

## Recommended Office Workflow

- Use one shared practice model for consistency.
- Save exercise milestones after each class.
- Encourage keyboard shortcuts early.
- Focus on production workflows rather than theory.
- Use real office examples where possible.
- Reinforce type vs instance understanding repeatedly.

## Before Each Session

- Send calendar invite.
- Upload exercise files.
- Order lunch 1-2 hours before the session, if applicable.
- Check that the demo machine has the right Revit version and files.

## During Each Session

- Keep demonstrations short.
- Let learners make mistakes during exercises.
- Use prepared troubleshooting examples.
- Leave time for questions and recap.

## After Each Session

- Share the completed exercise file.
- Send a short recap message.
- Set an optional homework exercise.
- Capture recurring questions for the next session.

## Assessment

Recommended assessment methods:

- Weekly mini exercises
- Final timed mock project
- Peer review of sheets and documentation
- Short certification-style task review

## Budget Notes

Planning assumptions:

- 2 sessions per week
- 1 hour per session
- 16 core sessions total
- Approximate duration: 8 weeks
- Lunch provided by office before or during session

Typical budget categories:

- Trainer time
- Lunch
- Printing and materials
- Certification exam vouchers
- Contingency
