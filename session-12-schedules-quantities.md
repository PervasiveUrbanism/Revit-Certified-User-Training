# Session 12: Schedules and Quantities

## Goal

Extract model data with schedules and understand how schedules support BIM coordination.

## Prerequisites

- A model with doors, rooms, and components
- Basic parameter awareness

## Key Concepts

- Schedules as database views
- Categories
- Fields
- Sorting and grouping
- Filters
- Formatting
- Itemize every instance
- Schedule data entry
- Hidden fields
- Calculated values
- Conditional formatting
- Quantity take-off

## Demonstration

Explain schedules as live views into the Revit project database. Show how model elements contain data that can be extracted, organised, filtered, and placed on sheets.

Demonstrate door, window, and room schedules. Use schedules as quality-control tools for missing values, inconsistent naming, duplicate numbers, and coordination checks. Show itemize every instance and direct schedule data entry.

## Exercise

1. Create a door schedule.
2. Add useful fields such as mark, type, width, height, and level.
3. Sort and group schedule data.
4. Filter the schedule.
5. Create a window schedule.
6. Create a room schedule.
7. Toggle Itemize every instance.
8. Enter and modify schedule data.
9. Apply simple formatting.
10. Place a schedule on a sheet.

## Checklist

- [ ] I understand that schedules read live model data.
- [ ] I can create a category schedule.
- [ ] I can add and reorder fields.
- [ ] I can sort, group, and filter data.
- [ ] I can use Itemize every instance.
- [ ] I can enter and modify schedule data.
- [ ] I can use schedules for quality control.

## Homework

- Create a furniture schedule.
- Review office schedule standards.
