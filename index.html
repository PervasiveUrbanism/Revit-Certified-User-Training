Revit Certified User Training

A practical office programme for Revit fundamentals, BIM workflows, documentation, collaboration, and Autodesk Certified User preparation.

View Schedule Editable Schedule

Course format

Short practical sessions for busy project teams

16 core sessions
1 hr per session
8 wks typical pace
4-10 learners

Session Rhythm

  • 10-15 minutes live demonstration
  • 30-40 minutes guided exercise
  • 5-10 minutes recap and questions
  • Short practice task between sessions

Training Setup

  • One workstation per learner
  • Dual screens preferred
  • Shared sample project for exercises
  • Exercise files and recap links added below
