# Session 14: Linked Models and Coordination Basics

## Goal

Understand linked model workflows, shared coordinates, and basic BIM coordination responsibilities.

## Prerequisites

- Basic project setup knowledge
- A sample host model and linked model

## Key Concepts

- Revit links
- CAD links
- Overlay and attachment
- Link positioning
- Reloading links
- Shared coordinates
- Internal Origin
- Project Base Point
- Survey Point
- Linked model visibility

## Demonstration

Explain why professional BIM workflows use separate models for architecture, structure, MEP, landscape, and consultants. Show how links allow coordination while preserving model ownership.

Introduce Internal Origin, Project Base Point, and Survey Point. Explain the difference between physically moving a model and managing its coordinate relationship.

## Exercise

1. Link a Revit model into a host project.
2. Test positioning options.
3. Reload and manage the link.
4. Adjust linked model visibility.
5. Review overlay versus attachment.
6. Inspect Project Base Point and Survey Point.
7. Discuss acquire and publish coordinate workflows.

## Checklist

- [ ] I can link a Revit model.
- [ ] I understand overlay versus attachment.
- [ ] I can reload and manage links.
- [ ] I can adjust linked model visibility.
- [ ] I understand the purpose of shared coordinates.

## Homework

- Review office coordination workflows.
- Compare consultant model positioning methods.
