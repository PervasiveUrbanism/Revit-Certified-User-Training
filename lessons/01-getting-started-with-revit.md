# Lesson 01: Getting Started With Revit

## Goal

Understand the Revit workspace, open a project, navigate views, and recognize the main tools used during a basic modeling session.

## Prerequisites

- Autodesk Revit installed
- Basic understanding of architectural drawings
- A sample project or Revit default template

## Key Concepts

- Project Browser
- Properties palette
- Ribbon tools
- View controls
- 3D navigation
- Levels and views

## Exercise

1. Open Revit and create a new architectural project.
2. Find the Project Browser and Properties palette.
3. Open a floor plan, elevation, section, and 3D view.
4. Practice zooming, panning, orbiting, and switching between views.
5. Save the project locally.

## Checklist

- [ ] I can create or open a Revit project.
- [ ] I can identify the main interface areas.
- [ ] I can switch between common view types.
- [ ] I can navigate a model in 2D and 3D.
